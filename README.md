---

## 🚀 How to Load in Chrome

1. Download using any option above
2. Open Chrome → go to `chrome://extensions`
3. Enable **Developer Mode** (top-right toggle)
4. Click **"Load unpacked"**
5. Select the `jarvistype-chrome-extension` folder
